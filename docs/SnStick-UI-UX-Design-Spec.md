## 1. 风格转向说明（v2.0 → v3.0）

| 版本 | 风格 | 用户反馈 |
| --- | --- | --- |
| v1.1 | 蓝青玻璃、克制选中态 | "太素" |
| v2.0 | 纯黑底、大面积蓝青渐变、扇形卡组、选中发光 | "没达到想要的效果" |
| **v3.0** | **靛蓝主色的 B 端数据平台风：分层实色、信息密度、细节精度** | 本轮目标 |

v3.0 的核心判断：用户想要的不是"更炫"，而是**专业工具的信任感**。参考系（Model-Flow 平台 12 个页面）展示的是一种成熟的 B 端设计语言——深蓝紫黑分层底色、单一靛蓝品牌实色、规整网格与列表、克制的选中态发光。视觉重心从"冲击力"转向"专业质感与信息效率"。

v2.0 四大特征在 v3.0 中的处置：

| v2.0 特征 | v3.0 处置 |
| --- | --- |
| 纯黑背景 `#000000` | 改为**深蓝紫黑 `#0F111A`**（带色彩倾向的深底） |
| 大面积蓝青绿渐变（选中卡整卡渐变、详情卡渐变） | **移除**。品牌色以实色出现：主按钮、选中态、边框点缀 |
| 磨砂玻璃/半透材质/扇形透视卡组 | **移除**。面板为哑光实色；卡片回归规整网格/列表（参考系全部页面均为规整排布） |
| 选中态强发光 | 收敛为**克制的边框发光**（仅选中/hover，`0 0 8px rgba(99,102,241,0.3)` 级别） |

策略卡组形态说明：参考系中不存在扇形/coverflow 排布；同类"模板/技能列表"页面（ref-06 Skill 中心）使用**规整卡片网格**。v3.0 建议策略卡回归网格或紧凑列表；扇形去留为待用户决策项（保留则需按 v3.0 色彩重绘材质，去掉渐变与玻璃）。

## 2. 设计依据与原则

参考系为 Model-Flow AI 本体智能应用平台的 12 个功能页面（元数据管理、本体建模、流程编排、Skill 中心、智能问答、图谱可视化等），覆盖列表页、画布页、配置页、对话页四种形态，设计语言高度一致，可作为完整规范依据。色值为截图目测估计值（标注"≈"），实施时以整体观感一致为准，允许 ±2 色阶微调。

设计原则（从参考系提炼）：

1. **分层实色**：背景按"页面底 < 侧栏 < 面板 < 表头/选中"四层递进，全部哑光实色，不用半透、模糊、渐变铺底。
2. **单一品牌实色**：全站只有一个品牌强调色（靛蓝 `#6366F1`），出现在主按钮、选中态、链接与点缀；不使用大面积渐变。
3. **色彩即信息**：分类标签、状态点、统计数字用低饱和深底 + 同色系亮字的标签系统编码类别，扫读即可区分。
4. **等宽数字**：所有数字（统计、表格、耗时、ID）等宽渲染，小数位对齐。
5. **8px 网格**：间距、内边距均为 8px 的倍数；信息密度高但不拥挤。
6. **克制反馈**：hover 背景提亮一档；选中态才有边框换色与淡发光；无大位移动效。

### 3.5 文字层级

| 层级 | 值 | 用途 |
| --- | --- | --- |
| 标题高亮 | `#FFFFFF` | 页面标题、选中菜单、关键统计 |
| 一级正文 | `#E2E8F0` | 卡片标题、正文、按钮 |
| 二级说明 | `#94A3B8` | 描述、未选中菜单、表头 |
| 三级辅助 | `#7A899F` 级（215 16% 55%） | 占位符、技术标注、弱提示（暗色面板上 ≥4.6:1，v3.1.1 起 AA 达标；原 #64748B 仅 3.58:1） |

警示文本/提示条统一走 `--warning` token，不得散用 `amber-*` 硬编码（回测页、AI 设置页已收敛）；amber 作为「自定义信号/龙头金色/交易状态」等**分类色**合法保留。

### 3.6 A 股金融语义（不变项，红线）

- 上涨红、下跌绿：沿用现有 `--bull`（红）/`--bear`（绿）原值，**不参考**参考系的绿成功/红错误语义（用途不同，不得混用）。
- 涨跌、阈值、评分、净值等数据口径与单位不变；红涨绿跌在任何主题下保持可辨。

### 3.7 浅色主题

参考系全部为暗色。v3.0 浅色主题降级为次要目标：保持结构一致，用中性浅灰分层 + 同一品牌色（浅色用深一档 `#1D4ED8`，v3.1 起）；不追求与暗色对等的精致度，后续按需专项调整。

## 6. 圆角、边框与阴影

| 元素 | 圆角 | 边框 |
| --- | --- | --- |
| 卡片/面板 | 8px | 1px `#252A3D` |
| 按钮 | 6px | 主按钮无边框；次按钮 1px |
| 标签/小控件 | 4px | 标签系统见 §7.3 |
| 输入框 | 6px | 1px，高 40px |
| 图标按钮 | 4–6px | 28×28px |

阴影与发光（克制原则）：

- 卡片常态：`0 2px 8px rgba(0,0,0,.2)` 或无阴影（哑光为主）
- 选中/hover 发光：`0 0 8px rgba(99,102,241,.3)` ——**仅选中态**，禁止给正文、表格、未选中卡片加发光
- 主按钮：`0 2px 8px rgba(99,102,241,.3)` 轻投影
- 不用玻璃拟态、backdrop-filter、大面积渐变描边

## 7. 组件规范

### 7.1 导航

- L1 底色；菜单项圆角 6px、内边距 8px 12px；未选中文字 `#94A3B8`、选中白字 + L3 底 `#262B4A`；可选左侧 2px 品牌色指示条；图标 16px 线性（Lucide 沿用）。

### 7.2 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | `#2563EB` 实色底、白字、圆角 6px、padding 8px 16px、hover `#3B82F6` |
| 次按钮 | L2 底 + 1px 边框 `#252A3D`、文字 `#E2E8F0`、hover 边框提亮 |
| 文字按钮 | 透明底、`#60A5FA` 文字、hover 提亮 |
| 虚线新建按钮 | 1px dashed 边框、`#94A3B8` 文字、hover 边框变品牌色 |
| 小按钮 | 圆角 4px、11–12px 字、padding 4px 8px |

### 7.3 标签系统（v3.0 核心组件）

- 结构：圆角 4px + **深色底（分类色 15–20% 透明度）+ 同色系亮字** + padding 2–4px 6–8px + 11–12px 字。
- 例：AI 标签 = `rgba(139,92,246,.18)` 底 + `#A78BFA` 字；内置标签 = `rgba(59,130,246,.15)` 底 + `#60A5FA` 字。
- 带关闭按钮的筛选标签：左侧 10px 分类色圆点。
- 形态细则（v3.1.1 品味审计后补充）：语义标签一律 4px 圆角；胶囊形（rounded-full）仅用于数字计数徽章；9px 小字全局提升至 10px（`workstation.css` 属性选择器兜底，低分屏可读性）；分类色是功能性「色彩即信息」，不统一为品牌蓝。

### 7.4 表格

- 表头：L2.5 底、13px/500、`#94A3B8` 字。
- 数据行：行高 44px、正文 13px、仅横向 1px 分隔线 `#252A3D`、**无斑马纹**；hover 行底 `#1E2233`；选中行底 `#262B4A` + 左 2px 品牌色条。
- 数字等宽右对齐（金额/百分比按现有列定义不变）。

### 7.5 卡片

- L2 底、8px 圆角、1px 边框、内边距 16–20px、hover 边框 `#333A52`。
- 选中卡片：1px `#2563EB` 边框 + 淡发光（唯一发光场景之一）。
- 列表卡片可带左侧 3px 分类色标记条。

### 7.6 输入与开关

- 输入框/下拉：L2 底、1px 边框、高 40px、圆角 6px、占位符 `#64748B`、聚焦边框品牌色。
- 开关：36×20px、开启 `#22C55E`、关闭 L2.5。
- 勾选框 14px、圆角 3px、选中 `#2563EB` 白勾；单选 16px 圆。

### 7.7 状态点与指示器

- 状态点 6px 实心圆（已发布绿/草稿灰）；带图标的步骤指示 16px 圆形色底 + 白色线性图标。

### 7.8 画布类页面（拓扑/图谱，SnStick 概念穿透、关联分析参考）

- 画布底 L0 + 点阵网格（1px 点、20px 间距、`rgba(42,45,62,.4)`）。
- 节点：L2 底、2px 分类色边框、圆角 6px；连线 1–2px 分类色、虚线表示未确认关系；hover 连线加粗变色。

## 8. 状态与交互

| 状态 | 表现 |
| --- | --- |
| 默认 | L2/L2.5 分层实色 |
| 悬停 | 背景提亮一档（L2→L2.5）、边框微亮；无位移 |
| 选中 | L3 底或品牌色 1px 边框 + 淡发光；表格行加左 2px 指示条 |
| 键盘焦点 | 2px 品牌色外环、2px 偏移 |
| 禁用 | 文字 `#64748B`、不改变可点击外观之外的表现 |
| 加载/空/错误 | 保留现有骨架、空态与错误组件，仅换色 |

动效：过渡 160–200ms ease；`prefers-reduced-motion` 全局降级（现有规则沿用）。不引入自动轮播、持续动画。

## 9. 图表与数据可视化

- 图表文字/网格/tooltip 从 `theme.ts` 按 v3.0 文字层级重配：轴标签 `#94A3B8`、强调 `#E2E8F0`、tooltip 底 `#1E2233`。
- 系列色沿用现有技术指标配色与涨跌红绿；不新增示意曲线。
- K 线、均线、成交量、净值曲线等金融语义与口径零变更。
