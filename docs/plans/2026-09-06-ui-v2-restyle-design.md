# SnStick UI v2.0 视觉升级设计（纯黑玻璃 + 扇形卡组）

> 日期：2026-09-06
> 状态：设计已获用户确认，待实施
> 前置：v1.1 规范 `docs/SnStick-UI-UX-Design-Spec.md`
> 视觉基准：`docs/design/v2-target-codex.png`（用户提供的 Codex 目标图）
> 改造边界：纯视觉改造，功能、数据、交互逻辑零变更

## 1. 背景与目标

v1.1（蓝青玻璃）落地后，用户反馈整体"太素"，希望有更强的视觉冲击力与现代化。用户提供了 Codex 目标图作为 v2.0 的视觉基准。本设计在 v1.1 的 token 架构与功能保留边界之上，翻转若干"克制决策"，达成：

- 纯黑底 + 玻璃卡的强对比暗色主题
- 选中元素整卡饱和品牌渐变 + 外发光
- 策略页 3D 扇形卡组（coverflow 模式）

## 2. 目标图解析（视觉事实）

来自 `v2-target-codex.png`：

- 背景：纯黑 `#000000`
- 品牌渐变：亮蓝 `#287BFF` → 青绿 `#10B981`（选中竖卡自上而下，参数卡自左向右）
- 玻璃卡：深色底叠白色半透（约 `rgba(255,255,255,0.06)`），1px 白描边（约 15% 透明度）
- 选中发光：蓝青外发光约 0.3 透明度
- 涨跌色：上涨红 `#F53F3F`，下跌绿 `#00B42A`（A 股语义不变）
- 布局：顶部全局导航 → 页头（标题+筛选+功能按钮）→ 中部扇形策略卡组（居中选中+左右箭头）→ 底部左表格/右策略详情层叠卡

该图为材质与配色依据，不是完整功能页面，不作为金融数据依据（沿用 v1.1 免责口径）。

## 3. v1.1 → v2.0 决策翻转清单

| 条款 | v1.1 | v2.0 |
| --- | --- | --- |
| 底色 | 深灰蓝 `hsl(210 8% 6%)` | 纯黑 `hsl(0 0% 0%)`（暗色） |
| 选中渐变浓度 | 局部薄叠层（34%/8%/20%） | 整卡可感知（约 55%/28%/38%） |
| 外发光 | 明确禁止 | 选中态启用（限定范围，见 §5） |
| 策略卡排布 | 单层横排 + -22° 微透视 | 3D 扇形对称（coverflow），选中居中 |
| 品牌端点色 | `#1260FF` / `#12DDBA` | `#287BFF` / `#10B981`（青色 `#00BFEF` 为过渡） |

保持不变：HSL 变量命名体系、`tf-theme` 主题机制、涨跌语义色原值、字体栈、圆角 token、功能保留表（v1.1 §10）全量有效。

## 4. Token 变更明细

### 4.1 暗色主题（`frontend/src/index.css` `html.dark`）

```css
--base: 0 0% 0%;
--surface: 220 14% 7%;        /* 玻璃卡实体底，近黑微冷 */
--elevated: 220 12% 11%;
--brand-blue: 40 123 255;     /* #287BFF */
--brand-mint: 16 185 129;     /* #10B981 */
--glass-selected: linear-gradient(160deg,
  rgb(var(--brand-blue) / .55),
  rgb(var(--brand-cyan) / .28) 50%,
  rgb(var(--brand-mint) / .38));
--glow-brand: 0 0 24px rgb(var(--brand-blue) / .30),
  0 0 8px rgb(var(--brand-cyan) / .25);
--glow-line: 0 0 0 1px rgb(var(--brand-cyan) / .45);
```

注：竖向选中卡用 160deg（近垂直）渐变，横向详情卡用 115deg（近水平）渐变，对应目标图两种方向。`--glow-brand` 为新增变量。

### 4.2 发光系统（新增）

- 应用对象（仅三类）：选中策略卡（`.sn-strategy-card--active` 及扇形居中卡）、当前导航项、选中状态标签（如"数据已同步"标签）。
- 不发光：数据表格、正文文字、普通按钮、图表、未选中卡片。
- 实现：`box-shadow: var(--glow-brand), var(--glow-line)`，纯 CSS，不新增滤镜层，不改 `pointer-events`。
- 降级：`@media (prefers-reduced-transparency: reduce)` 去发光；`prefers-reduced-motion` 已有全局规则继续生效。

### 4.3 浅色主题

保持 v1.1 克制色彩体系（纯黑玻璃只属于暗色），仅同步品牌端点 `--brand-blue` / `--brand-mint`；浅色发光透明度降至 0.18 级别，避免浅底光晕脏灰。

### 4.4 涨跌与语义色

`--bull` / `--bear` / `--warning` / `--danger` 原值不动。目标图的红绿（#F53F3F/#00B42A）与现行值（4 87% 60% / 152 67% 45%）视觉相近，不做全局替换，避免波及图表与历史组件。

## 5. 策略页扇形卡组（coverflow）

### 5.1 范围

仅 `Screener` 页标准/详细（normal/large）卡模式；紧凑（mini）模式保持自动换行不扇形；隐藏（hidden）模式不变。全部策略可达：扇形为可视窗口展示（居中 ±N 张），其余通过箭头/横滚到达，保留原排序。

### 5.2 视觉与交互

- 卡片 3D 扇形对称排列：居中卡正面全尺寸 + 整卡渐变 + 发光；两侧卡片按距离递增 Y 轴旋转与后退，透明度递减。
- 交互：左右箭头切换居中卡；点击侧卡 → 居中；悬停侧卡 → 归正预览；选中卡保留全部操作入口（参数设置/运行选股/监控回调，沿用 v1.1 §15 的原回调约定）。
- 键盘：左右方向键切换居中卡，焦点环沿用 `--focus-color`。
- 动效：仅切换瞬间的 transform 过渡（沿用既有 transition 时长）；无自动轮播、无持续运动。
- 降级：`prefers-reduced-motion` 时取消透视与位移，平铺网格；`useIsDesktop` 为 false 时平铺（移动端不做扇形）。

### 5.3 实现边界

- 新样式进 `frontend/src/styles/strategy-studio.css`（v1.1 已建），布局调整在 `Screener.tsx` 卡容器区域；不改数据获取、查询键、事件处理。
- CSS 使用独立 `rotate` / `translate` / `perspective` 属性，不覆盖 Framer Motion 既有进入动画（沿用 v1.1 §15.2 经验）。

## 6. 底部分屏增强

沿用 v1.1 §15 文件夹层叠详情区，顶层参数卡升级为整卡横向品牌渐变（115deg）+ 轻发光；其余层叠卡保持玻璃材质。左表格区逻辑不变。

## 7. 功能保留红线

- v1.1 §10「页面应用与功能保留」表全量有效。
- 不新增/删除：菜单、路由、表格列、参数、策略来源标签、密度模式、AI 入口、监控回调。
- 不改动：后端、API、查询键、状态存储、事件处理、用户配置。
- 不做：示意行情线入正式页、第二套主题状态、数据口径调整。

## 8. 实施阶段

1. **阶段一：token 层焕新**（低风险，全站生效）——改 `index.css` / `workstation.css` 变量值与发光规则；跑构建 + 离线 QA 预览。
2. **阶段二：策略页扇形**——`strategy-studio.css` 重写 + `Screener.tsx` 卡容器布局；跑构建 + 离线策略页 QA。
3. **收尾**：截图（深/浅/窄屏）与目标图对比，更新规范至 v2.0，用户视觉验收。

## 9. 验收标准

- `tsc -b` 与 `vite build` 通过；`qa` 两个离线样板 TypeScript 通过。
- 离线样板检查：深浅主题、扇形切换、箭头/点击/键盘交互、参数弹窗、紧凑/隐藏模式、390px 容器无横向溢出、无未捕获 JS 错误。
- 功能对照：抽查导航、路由、查询键、回调无 diff（纯样式文件 + 布局类名变更）。
- 用户视觉验收通过后，`SnStick-UI-UX-Design-Spec.md` 升版 v2.0 并记录验收。

## 10. 风险与回退

- 风险：纯黑底对既有半透明文字/边界的可读性影响 → 阶段一完成后在 QA 样板逐屏检查。
- 风险：扇形容器在窄屏溢出 → 降级平铺已内置；390px 容器检查纳入验收。
- 回退：样式按文件差异回退（同 v1.1 §14.2）；不回退用户既有 `vite.config.ts` 修改；不做全仓重置。
- 无数据迁移、无新依赖、无后端改动。
